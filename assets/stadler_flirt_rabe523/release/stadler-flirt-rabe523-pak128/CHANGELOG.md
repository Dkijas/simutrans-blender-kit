# Changelog — Stadler FLIRT RABe 523 (SBB) for pak128

## v0.1.0 — first test release

- Four-car SBB RABe 523 (Stadler FLIRT, first generation) for pak128.
- Fixed formation A–B–C(pantograph)–D, assembled from one depot click via a
  single-successor coupling chain; invalid consists impossible.
- Electric, 160 km/h, 2000 kW, ~120 t, 184 passengers, intro 2004.
- SBB livery painted in code (white body, red doors, red cab front, grey roof).
- Built entirely through the Simutrans Blender Kit (rig, 8-direction render,
  sprite sheet, .dat, reserved-colour validation, makeobj, install).
- Verified in a running pak128 game (assembles in order, electric, moves).
- Cost / running cost are provisional and need balancing.
