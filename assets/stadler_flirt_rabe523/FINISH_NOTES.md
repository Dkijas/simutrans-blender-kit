QA-driven pass over the finished FLIRT to see where the finish can improve. Written
so the work can continue on another machine (the conversation and Claude's local
memory do NOT travel — only this repo does).

## Finding 1 — axis B (int_c night windows): BENIGN, not shipped

Validator flagged **128 px near-glow-miss on int_c** vs 2 px on the other three cars
(int_b has an identical livery). Investigated to ground:

- The 128 px are all exactly (88,99,112), distance 2 from the window colour
  #57656F=(87,101,111). No near-miss to any other glow target (lamps clean).
- They sit at **fraction 0.12–0.42 of the body height — the roof/window-band seam**,
  bordering roof grey (#CDD2D8) and dark metal. They are **antialiasing of the top
  edge of the window band against the roof**, not dead windows.
- Real windows already light (242 exact px, same as int_b). `ortho_scale` is a fixed
  2.8284 on every car — the pantograph does NOT change render scale; it makes the
  silhouette taller, shifting the vertical framing, so more seam AA shows on int_c.
- A `snap_glow` recipe (max_dist=2) changes exactly those 134 px total (compare
  confirms) and clears the warning, BUT at night it **lights a thin yellow line along
  the roofline** (day change is (1,2,1), invisible). A lateral change / faint halo,
  not an improvement. **NOT shipped.**

Lesson: near-glow-miss can flag legitimate edge AA. Verify with pixel location +
a day→night preview (swap #57656F → #D3C380, the engine's night colour) before
snapping. Method scripts were throwaway (scratchpad), not committed.

## Finding 2 — axis C (squat cross-section): OPEN LEAD, measured

The train reads "small/low" in-game. This is objective, from the model's own numbers
vs spec.json's measured dimensions (25 m/tile):

| | real (m) | true (·TW) | model (·TW) | model/true |
|---|---|---|---|---|
| width  | 2.88 | 0.115 | 0.196 | **1.70×** |
| height | 4.15 | 0.166 | 0.184 | **1.11×** |

Cross-section aspect **H/W: real 1.44, model 0.94** (wider than tall = squat). The
legibility fatten went into **width (1.70×) but not height (1.11×)**. To match the
width fatten, `Body.height` would be ≈ 0.282·TW; it is 0.184 (`flirt.py` class
`Body`).

**Proposed experiment (NOT done):** raise `Body.height` (e.g. 0.184 → ~0.23–0.28·TW),
re-render, and judge with a zoomed before/after AND an in-game capture — the author
tuned proportions against the catenary (civia lesson), so **verify pantograph/roof
clearance under the wire before shipping**. Given two prior visual false alarms
(diagonal gap; axis B), confirm visually before declaring an improvement.
