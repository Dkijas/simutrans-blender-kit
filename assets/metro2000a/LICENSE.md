## A note on references — read this one, it is different

This model was built from a **drawing we do not own**, and that distinction matters
more here than on the other two.

The geometry, the door positions, the livery layout and the colours were read off
the side elevation of car M-2004 in the CRTM's *"Breve historia de los Trenes de
Metro de Madrid"* (<https://www.crtm.es/media/161812/metro_historico_historia_trenes.pdf>),
drawn by **Miguel Ángel Delgado**, with technical commentary by **Manuel González
Márquez** of Metro de Madrid's Material Móvil department.

That drawing is **theirs, not ours**. It is not redistributed in this repository and
must not be: `.gitignore` excludes `assets/*/references/` precisely because a
licence covering somebody else's work would be a false statement. What is licensed
above is the 3D model made *after consulting* it — the same relationship a model
built from a photograph has to the photograph.

If you need the drawing, get it from the CRTM at the URL above, where it is
published. If you need to know exactly which pixels were measured and how, that is
recorded in `spec.json` under `reference`, with the render settings, so the
measurement can be re-run rather than believed.
